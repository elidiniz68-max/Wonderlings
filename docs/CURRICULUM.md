# Wonderlings — Learning Curriculum (MVP Spec)

**Purpose.** Exactly what each age band learns, mapped to worlds, mini-game
slots, and MVP coverage. Step 6 (mini-game design) turns each row below into
real gameplay; the parent dashboard (SCREEN_FLOW.md) reports against these
objectives.

**Philosophy.**
- **Mastery over speed.** No timers in MVP. A child who takes 30 seconds and
  gets it right beats a child who rushes.
- **Invisible assessment.** Every challenge is data. There is no "test mode"
  — the parent dashboard translates play into progress language.
- **Concrete before abstract.** Every band starts with the thing you can see
  and touch (aliens you count, words you hear), then fades the scaffolding.
- **One new thing at a time.** A round teaches OR tests, never both at once.
- **Not a certified curriculum.** This maps *loosely* to US Common Core /
  NGSS and UK Key Stages as a guide for parents — Wonderlings is a learning
  adventure, not an accredited school program. Never claim otherwise.

**How to read the tables.** "Can-do" = the observable skill. "Slot" = the
MVP mini-game that teaches it. "Status" = whether the prototype covers it
today.

## Difficulty progression model

**Within a mission (all bands).** 5 rounds escalate: round 1 is a warm-up
(~70% of band difficulty), rounds 2–4 at band level, round 5 is a stretch
challenge. The last round should feel *earned*.

**Across sessions (adaptive — MVP-lite now, full later).**
- Track rolling accuracy **per topic** (not just per subject).
- <60% on a topic → easier items + more visual/verbal scaffolding next time.
- >85% → stretch items from the next rung up.
- MVP implements: static pools + round escalation. The per-topic tracker
  lands with the parent dashboard ("areas to practice" needs this data).

**Mastery.** A topic is *mastered* at ≥80% over the last 20 attempts →
badge + parent dashboard note ("🔥 Fractions: mastered!"). Mastery never
expires, but revisit missions keep it fresh. No grades, no percentiles, no
leaderboards against other children — ever.
